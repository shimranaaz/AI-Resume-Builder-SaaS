Environment Variables

Configure backend and frontend environments before running the application.

Backend (.env)

backend/.env 
PORT=5000
JWT_SECRET=your_jwt_secret
MONGODB_URI=your_mongodb_uri
IMAGEKIT_PRIVATE_KEY=your_imagekit_private_key
GROQ_API_KEY=your_groq_api_key

# Gmail SMTP fallback
GMAIL_SMTP_HOST=
GMAIL_SMTP_PORT=
GMAIL_SMTP_USER=
GMAIL_SMTP_PASS=
GMAIL_SENDER_NAME=

# Resend transactional email
RESEND_API_KEY=

# Razorpay payment gateway
RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=
RAZORPAY_WEBHOOK_SECRET=
Never commit .env files to GitHub.

Add .env to your .gitignore before your first commit. Leaked secrets should be rotated immediately.

Frontend (.env)

frontend/.env 
VITE_BASE_URL=
VITE_RAZORPAY_KEY_ID=
VITE_BASE_URL The base URL of your deployed backend API (e.g. https://api.yourapp.com). Used for all frontend HTTP requests.
VITE_RAZORPAY_KEY_ID Your public Razorpay Key ID, used client-side to initialize the checkout widget. The secret key stays on the backend only.

Storage

Database Setup — MongoDB Atlas

Provision a free MongoDB Atlas cluster and connect it to your backend.

1

Create a MongoDB Atlas account

Sign up for a free account at the MongoDB Atlas website.

2

Create a cluster

Choose the free shared tier (M0) and select a region close to your backend host.

3

Create a database user

Under Database Access, create a username and password with read/write permissions.

4

Whitelist your IP address

Under Network Access, add your current IP — or 0.0.0.0/0 for development.

5

Get your connection string

Click "Connect" on your cluster and copy the provided URI string.

6

Add MONGODB_URI

Paste the connection string into your backend .env file as MONGODB_URI.

Billing

Payment Integration — Razorpay

How a purchase flows from checkout to premium access activation.

User Purchase
Checkout Open
Payment Success
Webhook Verification
Premium Access Activated
Security note

Every Razorpay webhook payload is verified against RAZORPAY_WEBHOOK_SECRET using an HMAC signature before access is granted. Never activate premium access on the client-side success callback alone — always wait for server-side webhook confirmation.

Trust

Security

Measures built into the platform to protect user data and transactions.

JWT Authentication

Signed, stateless tokens validate every authenticated request to the API.

Password Hashing

User passwords are hashed with bcrypt before being stored — never stored in plain text.

Razorpay Signature Verification

All payment webhooks are validated against an HMAC signature before access is granted.

Environment Variable Protection

Secrets live only in .env files, excluded from version control via .gitignore.

Secure API Access

Protected routes require a valid bearer token; rate limiting guards against abuse.

HTTPS Deployment

Both Netlify and Render serve traffic over HTTPS by default, with automatic certificate management.

Common Questions

FAQ

Answers to the questions developers ask most often.

The frontend sends structured profile data to /api/ai/generate, which forwards a prompt to the Groq API. The response is parsed into resume sections and returned to the client for rendering and editing.
After checkout, Razorpay sends a webhook to the backend. The backend verifies the payload signature using RAZORPAY_WEBHOOK_SECRET before activating premium access — client-side confirmation alone is never trusted.
All user, resume, and transaction data is stored in MongoDB Atlas. Passwords are hashed with bcrypt; resumes are stored as structured documents linked to the owning user.
Yes. The frontend is a static Vite build deployable to any static host, and the backend is a standard Node.js/Express app deployable to any Node-compatible host.
AI calls are isolated in a single service module on the backend. Swap the Groq client and request/response mapping in that module to point at a different provider.
Resume templates live in the frontend's templates directory as individual React components. Duplicate an existing template component and adjust the layout and styling to create a new one.
