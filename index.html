You get the complete React + TypeScript frontend, Node.js + Express backend, MongoDB schemas, all 4 AI modules (ATS Checker, Resume Builder, LinkedIn Analyzer, Interview Coach), plus the User, Sales, and Admin dashboards — along with deployment documentation and email support.
What's the difference between Source Code and Code + Installation?

The Source Code plan gives you everything to deploy yourself using our documentation. The Code + Installation plan means we do all the setup for you — MongoDB Atlas, Razorpay webhooks, Groq API integration, custom domain, and deployment — so your platform is live the same day.
Can I use this commercially and sell subscriptions?
+
Yes. Once you purchase the source code, you own it fully. You can launch it as your own SaaS, charge subscriptions, white-label it under your brand, and keep 100% of revenue — no royalties or licensing fees, ever.
What AI model does the platform use?
+
The platform is built on the Groq API, which provides ultra-fast AI inference. You simply plug in your own Groq API key — it takes under a minute to configure. Groq offers a generous free tier to get started, and paid plans scale with your usage.
How does the Razorpay payment integration work?
+
Razorpay handles all subscription billing, one-time payments, and webhooks. You connect your own Razorpay account, configure your pricing plans from the Admin panel (no code needed), and payments flow directly into your account. Webhook handling for failed and successful payments is already built in.
